# Система иконок «OTDYH23 Icons»

Фирменная SVG-библиотека сайта «Отдых.23».

Файлы:
- `js/otdyh23-icons.js` — разметка иконок и функция доступа;
- `css/icons.css` — стили иконок и бейджей.

Библиотека пока не подключена к `index.html`. Подключать только при внедрении в интерфейс.

---

## Стиль

- оригинальные минималистичные inline SVG;
- без emoji, icon fonts и внешних библиотек;
- тонкий контур, без заливки;
- `viewBox="0 0 24 24"`;
- `stroke="currentColor"`;
- `stroke-width="1.5"`;
- `stroke-linecap="round"` и `stroke-linejoin="round"`;
- единый визуальный вес и плотность;
- спокойный премиальный характер;
- без туристических клише и мультяшности.

---

## Размеры

Базовый холст: 24×24.

Рекомендуемые CSS-размеры:

| Класс | Размер | Применение |
|---|---|---|
| `.otdyh23-icon--sm` | 16px | плотные списки, мелкие подписи |
| `.otdyh23-icon--md` | 20px | бейджи, карточки удобств |
| `.otdyh23-icon--lg` | 24px | акцентные блоки |
| `.otdyh23-icon` | 1.25em | рядом с текстом |

В бейдже `.amenity-badge` иконка: 20px на desktop, 18px на mobile.

---

## Цвета

Цвет задаётся через `currentColor` / CSS `color`.

Рекомендации:
- основной текст интерфейса: `var(--ink)` / `var(--deep)`;
- морской акцент: `#6F9EA8` (класс `.otdyh23-icon--sea` или цвет в `.amenity-badge__icon`);
- не перекрашивать крупные поверхности в голубой или бирюзовый;
- морской цвет — только в иконках, линиях и hover-акцентах.

---

## Правила использования

1. Брать иконки только из `OTDYH23_ICONS` / `getOtdyh23Icon()`.
2. Не подключать Font Awesome, Lucide, Remix и аналоги.
3. Не заменять SVG на emoji.
4. Сохранять контурный стиль: не добавлять заливки и эффекты «ради красоты».
5. Не дублировать ключи и не создавать вторую иконку того же смысла под другим именем без причины.
6. Для удобств комнаты предпочитать компонент `.amenity-badge`.
7. Hover у бейджа не усиливать: без подъёма, без тяжёлой тени, без заметного масштаба.
8. Учитывать `prefers-reduced-motion`, если вокруг иконки появляется анимация.

## API

### `OTDYH23_ICONS`

Объект: ключ → строка с полным `<svg>...</svg>`.

### `getOtdyh23Icon(name, className = '')`

- возвращает SVG по ключу;
- если передан `className`, добавляет его в корневой `<svg>`;
- для неизвестного ключа возвращает пустую строку `''`.

Пример:

```html
<span class="amenity-badge">
  <span class="amenity-badge__icon"></span>
  <span class="amenity-badge__label">Wi-Fi</span>
</span>
```

```js
const icon = getOtdyh23Icon('wifi', 'otdyh23-icon otdyh23-icon--md');
badgeIcon.innerHTML = icon;
```

---

## Бейдж `.amenity-badge`

Состав:
- иконка слева (`.amenity-badge__icon`);
- текстовая подпись справа (`.amenity-badge__label`).

Характер:
- спокойный тёплый фон;
- тонкий контур;
- радиус 16px (14px на mobile);
- морской акцент только через цвет иконки;
- без тяжёлой тени;
- без заметного hover.

Обёртка-сетка: `.amenity-badges`.

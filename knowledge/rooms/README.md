# Проект «Отдых.23»

Версия: 1.0 (рабочая база знаний)

---

# Назначение проекта

«Отдых.23» — официальный сайт гостевого дома в Лазаревском.

Проект создаётся как долгосрочная система управления сайтом, контентом и знаниями.

Сайт должен отличаться от большинства сайтов гостевых домов и восприниматься как сайт небольшого премиального бутик-отеля.

Основные ощущения, которые должен испытывать посетитель сайта:

- спокойствие;
- тишина;
- лёгкость;
- доверие;
- ощущение отдыха ещё до бронирования.

---

# Главная задача сайта

Не просто показать комнаты.

Главная задача сайта — помочь человеку представить свой будущий отдых и спокойно принять решение о бронировании.

Продажа должна происходить мягко.

Без давления.

Без искусственного дефицита.

Без агрессивных призывов.

---

# Позиционирование

Гостевой дом подходит людям, которые ценят:

- тишину;
- комфорт;
- чистоту;
- спокойную атмосферу;
- семейный отдых;
- качественный сервис;
- порядок.

Мы не позиционируем себя как место для шумных компаний.

---

# Целевая аудитория

Основная аудитория:

- пары;
- семьи с детьми;
- родители с ребёнком;
- путешественники 30–55 лет.

# Назначение папок

## data/

JSON-файлы.

Источник данных для сайта.

Каждая категория комнаты хранится отдельно.

Примеры:

```
comfort.json
deluxe-2.json
deluxe-3.json
family.json
```

---

## images/

Реальные фотографии.

Все фотографии разложены по категориям и сценариям размещения.

Главная фотография каждого сценария начинается с префикса:

```
00_
```

---

## knowledge/

База знаний проекта.

Все текстовые материалы хранятся здесь.

Этот раздел является главным источником информации.

При изменении описаний сначала редактируются файлы в knowledge, затем синхронизируются JSON.

---

# Структура раздела knowledge

```
knowledge/

README.md

brand/

rooms/

territory/

service/

content/
```

# Архитектура раздела «Комнаты»

# Принципы разработки

Любые новые функции должны использовать уже существующие универсальные механизмы.

Запрещается создавать отдельный код под конкретную комнату.

Все категории работают через единый шаблон.

---

# Работа с фотографиями

Используются только реальные фотографии гостевого дома.

Запрещается заменять реальные фотографии искусственно созданными изображениями.

Для каждого сценария существует собственная мини-галерея.

Главное фото определяется автоматически по имени файла с префиксом:

```
00_
```

---

# Контент

Контент создаётся отдельно от программного кода.

Сначала утверждается текст.

После утверждения он переносится в JSON.

JSON не является местом написания текстов.

---

# Дизайн

При любых изменениях необходимо сохранять утверждённую концепцию.

Основные принципы:

- спокойствие;
- минимализм;
- воздух;
- свет;
- натуральные цвета;
- ощущение дорогого отдыха.

Не использовать:

- кричащие цвета;
- визуальный шум;
- перегруженные карточки;
- дешёвые эффекты.

---

# Что нельзя менять без согласования

Запрещается самостоятельно изменять:

- архитектуру сайта;
- структуру JSON;
- структуру knowledge;
- структуру папки images;
- цветовую концепцию;
- логику работы комнат;
- сценарии размещения.

---

# Общий принцип проекта

Сначала создаётся структура.

Потом данные.

Потом тексты.

Потом дизайн.

Последний этап — финальная полировка.

Проект развивается постепенно.

Каждый новый этап должен использовать уже существующую архитектуру, а не создавать новую.

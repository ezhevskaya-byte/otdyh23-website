# Комната Комфорт — Отдых.23

## Тип номера

Комфортный номер гостевого дома «Отдых.23».

Номер подходит для размещения:
- 2 гостей;
- 3 гостей.

В зависимости от количества гостей используется разная организация спальных мест.

---

# Сценарии размещения

## 01_Для_двух_гостей

Размещение для двух гостей.

Особенности:
- основное двуспальное место;
- комфортное пространство для отдыха двух человек;
- подходит для пар и индивидуальных путешественников.

Фотографии сценария:
папка `01_Для_двух_гостей`

---

## 02_Для_трёх_гостей

Размещение для трёх гостей.

Особенности:
- подготовка дополнительного спального места;
- оптимально для небольшой семьи или компании из трёх человек;
- сохранение удобства и свободного пространства номера.

Фотографии сценария:
папка `02_Для_трёх_гостей`

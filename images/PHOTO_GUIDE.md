# PHOTO GUIDE — Отдых.23

## Назначение

Эта папка предназначена для хранения всех фотографий проекта сайта.

Фотографии должны быть распределены по смысловым разделам.

Не загружать фотографии хаотично.

Каждое изображение должно иметь понятное название.

Пример:

Komfort_2guests_room_01.jpg

а не:

IMG_12345.jpg


# Структура

## 01_Hero_Главный_экран

Фотографии для первого экрана сайта.

Требования:
- самые сильные визуальные кадры;
- передают атмосферу отдыха;
- подходят для полноэкранного отображения.


## Комнаты

Каждая комната разделяется по сценариям размещения.

Это важно, потому что:
- меняется расстановка мебели;
- меняется количество гостей;
- меняется визуальная подача.


## Бассейн

Фото:
- день;
- вечер;
- зона отдыха;
- шезлонги.


## Территория

Фото:
- двор;
- зелёная зона;
- детали.


## Терраса

Фото:
- зона отдыха;
- мебель;
- атмосфера.


# Правила для Codex

При создании сайта:

1. Использовать только фотографии из этой папки.
2. Не использовать стоковые изображения.
3. Не объединять разные сценарии размещения комнат.
4. Показывать реальные варианты проживания.
5. Лучшие фотографии использовать в главных блоках.
